# HEAVEN Google Sheet Check-in Bot

เวอร์ชันนี้เขียนคะแนนลง **Google Sheet จริง (Attendance_S4)** โดยตรง แทนที่จะเขียนลง Firebase

**วิธีใช้ในห้อง Discord:** เหมือนเดิม — พิมพ์ชื่อบอส (เช่น `Icarutier`) พร้อมแนบรูป check-in ในข้อความเดียวกัน

**สิ่งที่บอทจะทำ:**
1. อ่านรูปด้วย AI ดึงรายชื่อคนที่เข้าร่วม
2. หาคอลัมน์ในชีตที่ตรงกับ "ชื่อบอสนี้ + วันที่วันนี้"
3. หาแถวของแต่ละคนจากคอลัมน์ Member
4. กรอกค่าคะแนนตามตาราง `BOSS_POINTS` ในโค้ด (แก้ตัวเลขในนั้นได้ตามจริง)

**บอทจะ "ไม่กล้าเดา" และหยุดแจ้งเตือนแทน เมื่อ:**
- หาคอลัมน์ของบอส+วันที่นั้นไม่เจอ (แปลว่ายังไม่ได้เตรียมคอลัมน์ไว้ในชีต)
- เจอมากกว่า 1 คอลัมน์ที่ตรงกัน (เช่น บอสเกิดซ้ำวันเดียวกันหลายรอบ)
- หาชื่อสมาชิกในชีตไม่เจอ (จะข้ามคนนั้น แต่บันทึกคนอื่นตามปกติ)

---

## เตรียมของเพิ่มจากเดิม (นอกเหนือจาก Discord Bot + Anthropic API)

ดูขั้นตอนละเอียดที่คุยไว้ในแชท สรุปสั้นๆ:
1. เปิด Google Sheets API ใน Google Cloud Console
2. สร้าง Service Account → ดาวน์โหลด JSON key
3. Share Google Sheet ให้อีเมลของ Service Account (สิทธิ์ Editor)
4. คัดลอก Spreadsheet ID จาก URL

## Deploy ขึ้น Railway

เหมือนกับบอทตัวก่อนหน้า: อัปโหลดโฟลเดอร์นี้ขึ้น GitHub repo ใหม่ → Railway → New Project →
Deploy from GitHub repo → ใส่ตัวแปรใน Variables ตาม `.env.example` (5 ตัว) → รอ deploy → เช็ค Logs
ว่าขึ้น `✅ บอทออนไลน์แล้ว`

## ⚠️ สิ่งที่ควรทดสอบก่อนใช้จริง

ตารางของคุณมีบางบอส (โดยเฉพาะกลุ่ม Lv.135+ อย่าง Nevaeh/Icarutier/Motti/Lucus) ที่มีคอลัมน์
คู่กัน 2 ช่อง (เช่นเห็นค่า 5 ตามด้วย 2.5) ซึ่งผมไม่แน่ใจ 100% ว่าหมายถึงอะไร (คะแนนฐาน+โบนัส
กลางคืน หรืออย่างอื่น) — **บอทเวอร์ชันนี้เขียนแค่คอลัมน์เดียวที่ตรงกับชื่อบอส** ยังไม่รองรับ
คอลัมน์คู่นั้นอัตโนมัติ แนะนำให้ทดสอบกับบอสกลุ่มนี้ด้วยตาเปล่าก่อน 2-3 ครั้ง แล้วดูว่าผลลัพธ์
ตรงกับที่ตั้งใจไหม ก่อนปล่อยให้บอททำงานแทนทั้งหมด
